### AI, built for humans

We build speech and language AI for Nepali and the other low-resource languages of Nepal.
From Lalitpur, for the way we speak and work.

Most speech technology is built for languages with millions of hours of transcribed audio.
Nepali is not one of them. We work on the problems that creates: collecting data that does
not exist yet, and building models that hold up with less of it.

## Open source

We release the parts of our work that are useful to others building for Nepali, including
models and the benchmarks used to measure them. Every published accuracy figure is one we
measured ourselves, with the scoring code alongside it so anyone can check.
